# Sources and Credits

## Coursework

The materials are from Cooper Union’s 2024 **STEM Saturdays, Inventor’s Lab: Data Visualization**. The original final presentation credits **Shaoxuan Xiong as producer** and **Richard Feng as editor**. The bilingual rehearsal document includes speaker labels and is retained as part of the collaboration record.

## Employment dataset

The original final presentation cites Kaggle, and the speaker notes identify the dataset as *Employment to Population Ratio for USA*. The matching public dataset listing is [Employment-to-Population Ratio for USA (1979–2022), published by asaniczka on Kaggle](https://www.kaggle.com/datasets/asaniczka/employment-to-population-ratio-for-usa-1979-2023).

The repository uses the saved classroom workbook. It is not a fresh download or a claim that its year labels have been independently validated against the upstream dataset. See [data notes](DATA_NOTES.md).

## Penny-mass activity

[ASDL’s Active Learning Materials](https://asdlib.org/activelearningmaterials/activities/) lists *Penny Statistics with Data Set* and credits **Jordan Katz, Denison University**. The original attachment name identifies the Katz penny-mass activity. This repository preserves the classroom’s worked copy and distinguishes its separate worksheet subsets.

## Titanic

The workbook contains the familiar 891-row Titanic passenger training-table structure. A public reference for that dataset family is the [Kaggle Titanic competition data page](https://www.kaggle.com/competitions/titanic/data). The saved workbook does not retain its original download URL, so that page is a reference rather than a verified record of the classroom download.

## Other classroom materials

The settlement workbook identifies its exercise as *chart battle: stacked areas vs. stacked bars*. Its original download URL and time unit are not recorded in the saved file. The program-selection deck does not include its underlying audience/cost workbook or a complete data-source citation.

The source datasets and teaching materials are credited to their respective creators; preserving a worked classroom file does not make its underlying data an original data collection.
