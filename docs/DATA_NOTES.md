# Data Notes

## Original coursework and repository preparation

The Excel, PowerPoint, and Word files are unchanged copies of the saved coursework. Repository preparation added descriptive filenames, folders, navigation, CSV exports, a speaking-note transcription, and two preview images rendered from the existing final presentation. No new statistical model or corrected version of the original analysis is implied. The added presentation PDF is a reading edition with reflowed original text and selected chart overviews; the original PPTX retains all layouts and animation builds. The English and Chinese project-and-learning PDFs provide a separate explanation of the work and course practice.

CSV exports use saved Excel values. Formula results come from the workbook’s cached values; the files were not recalculated or resaved. The Excel originals remain the reference for formulas, charts, formatting, and supplementary calculations.

## Employment data

- The workbook contains 44 rows labelled 1979–2022. Sheet1 has 122 columns, including subgroup ratios and a population column. Percentage ratios are stored as values on a 0–100 scale.
- A subtraction of two percentage ratios is a **percentage-point difference**, not a relative percent change.
- Year alignment needs checking before linking changes to specific events. For example, the archived age table gives 51.3 for ages 16–24 in the row labelled 2020, followed by 45.6 in the row labelled 2021, while the presentation discusses the pandemic beginning in 2020. The repository preserves the saved labels and values rather than silently correcting them.
- Some workbook comparisons sum annual percentages, including the gender-by-education summaries on Sheet7. Such sums are not population-weighted employment ratios or counts of employed people. The corresponding CSV exports contain the annual observations rather than those summary totals.
- Differences between groups and coincident historical events are descriptive evidence. The charts alone do not establish why a person was employed, the cause of a group difference, a group’s industry composition, or the effect of an individual policy. The original presentation’s stronger explanations are retained as classroom interpretations.

## Titanic data

The passenger export has 891 rows. Missing ages and cabins remain blank. The workbook records 342 survivors. Sheet6 divides survivor counts by the total number of survivors: for example, `136 / 342` is the first-class share of survivors. To calculate survival probability within first class, the denominator would instead need to be all first-class passengers.

## Penny mass data

The workbook’s `Raw Data` sheet contains 358 populated measurement rows, Sheet1 contains 645, and Sheet2 contains 528. Formatting extends beyond the populated rows in some sheets. The CSV counts use populated year and mass fields, not Excel’s formatted range size. Sheet2 is an additional subset and must not be added to the other sheets as if it represented new measurements.
