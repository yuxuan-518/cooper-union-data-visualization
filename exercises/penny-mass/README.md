# Penny Mass Analysis

An Excel exercise comparing coin measurements and distributions. The saved workbook contains year, mass in grams, and mint labels (`D` for Denver and `P` for Philadelphia), together with averages, population standard deviation, frequency calculations, normal-density calculations, and three charts.

- [Original workbook](analysis.xlsx)
- [Raw Data worksheet: 358 measurement rows](data/raw-data-sheet.csv)
- [Sheet1: 645 measurement rows](data/sheet1-measurements.csv)
- [Sheet2: 528 rows from an additional subset](data/sheet2-subset.csv)

The saved measurements are split across worksheets. `Raw Data` holds earlier-year measurements, while Sheet1 contains later-year measurements and calculations. Sheet2 contains an additional subset; its selection rule is not recorded in the saved file. These exports should be read separately rather than concatenating all three as independent observations.

The exercise’s filename points to the Katz penny-mass activity. [ASDL’s original activity listing](https://asdlib.org/activelearningmaterials/activities/) credits Jordan Katz, Denison University. The archived classroom workbook is a worked copy, not a claim that I collected the source measurements.

## 中文简介

这个练习使用硬币年份、质量和铸造地点数据，进行平均数、标准差、频数和正态分布密度计算。原件中的测量值分散在三个工作表里，CSV 分别导出，避免把重叠的子集当成新的独立样本。数据活动来源署名为 Jordan Katz，不把课堂提供的数据写成个人采集。
