# 数据可视化与叙事

[English](README.md) | **简体中文**

这个仓库整理了我在 **2024 年 Cooper Union STEM Saturdays 项目 Inventor’s Lab: Data Visualization** 中完成的数据可视化材料，包括一个美国就业数据期末项目，以及四个课堂练习。

## 期末项目：美国就业数据中的群体差异

不同年龄、教育背景和性别的就业情况有什么差异？这个项目将标注为 **1979—2022 年**的数据整理成分类表格、折线图和差值计算，再通过 **22 页演示文稿**与**中英双语讲稿**，向听众解释图表中的比较和变化。

原演示文稿署名为 **Shaoxuan Xiong（制作）**和 **Richard Feng（编辑）**。讲稿保留了两位讲者的分工标记、排练提示和词汇注释。

这个项目体现了分类整理数据、计算群体差值、选择图表和进行口头讲解的练习过程。原演讲中的历史解释属于课堂分析；仓库的[数据说明](docs/DATA_NOTES.md)列出了再次使用结果时需要检查的具体问题，包括年份对应关系和年度百分比求和的含义。
